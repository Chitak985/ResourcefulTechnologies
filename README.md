# ResourcefulTechnologies

This mod adds numerous new ISRU parts, some of which are inspired by KSPIE in new and improved variants! You can finally make a flying factory to power antimatter and fusion engines using just bussard scoops, or make a processing chain to get useful resources from gas giants!

## Dependencies

- **SystemHeat**: Required for the ISRU modules to work as they are not designed to work with the stock heat system.
- **ModuleManager**: Required for other mod compatability and some parts of this mod.
- **B9 Part Switch**: Used for tanks and other storage containers this mod adds.
- **StationPartsExpansionRedux**: Needed for the artificial gravity ring functionality of some ISRU parts, like very big particle accelerators.

## Compatible Mods

- **FarFutureTechnologies**: A mod that should go along with this one, it provides engines and a few ISRU parts of its own to complement this mod.
- **KSPIE**: There are no conflicts with KSPIE and it has similar ISRU modules to the ones this mod has, but KSPIE does use the same resources as ResourcefulTechnologies does.
